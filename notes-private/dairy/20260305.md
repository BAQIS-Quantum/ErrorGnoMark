   - 以下信息需要仔细理解，怎么体现在egm整体设计上：

                到 2033 年，某条量子计算路线能否达到 “utility-scale operation”，即其 computational value exceeds its cost（计算价值超过其成本）。这就是最核心的总指标。

                这一定义背后，DARPA 实际考察的不是“多少物理比特/逻辑比特”这样单一数字，而是下面几类系统级指标：

                可建造性：是否存在一条近期开建、10 年内可实现的容错量子计算机路线。DARPA 在 US2QC/QBI 中明确关注的是能在较短周期内落地的 fault-tolerant 路线，而不是无限期远景。

                系统完整性：机器的组件、子系统、接口、工作模式、用户接口是否完整定义，能否形成自洽的系统架构。

                研发可执行性：是否有可审查的 R&D plan、风险清单、风险缓解步骤、原型验证方案。

                硬件可验证性：Stage C 会做 component testing、direct hardware evaluation、major prototype 的 system-level performance assessment，也就是直接看关键器件、子系统和原型机性能。

                应用有效性：是否能通过 application and algorithm co-design 证明该机型在目标任务上真的有实用价值，而不是只在实验室指标上“看起来不错”。

                开工准备度：完成 Stage C 的团队，要达到 DARPA 认为可以立即进入最终设计和建造的程度。

                所以，若写成一句更准确的话，可以说：

                DARPA 所谓 2033 年关键节点，并非以某个固定物理比特数或逻辑比特数为统一门槛，而是以“计算价值超过成本”为总目标，并围绕可建造性、系统完整性、关键部件验证、原型系统性能和应用共设计等系统级指标进行第三方验证。
